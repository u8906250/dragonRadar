隱私權政策

最後更新：2026 年 11 月 13 日（「雷達統計」頁公開列出活動來自哪些 Threads 帳號：只寫帳號名稱和次數，可以要求不列）

洋流雷達（以下稱「本服務」）是一個網頁工具，從 Threads 的公開貼文中找出「某時某地的免費發放或可參加的活動」，在雷達畫面上顯示相對位置。本政策說明本服務處理哪些資料，以及如何處理。點標題可以切換的其他雷達（例如狗狗陪伴、羽球臨打、美食品味）是同一個服務，一樣適用本政策。

一、網站使用者

  • 不需要註冊或登入。本服務不要求你提供姓名、Email、電話或任何帳號。
  • 位置：你允許定位後，瀏覽器會把你的大略座標送到本服務的伺服器，只用來查詢附近的發放資訊。伺服器不儲存你的座標，也不記錄你的位置軌跡（例外：開了手機通知的，見下面「通知」）。距離與方位是在你的手機上計算。
  • 手機上的設定：你選擇的主題、雷達範圍、手動設定的位置，只存在你自己瀏覽器的 localStorage，不會傳到伺服器。
  • 通知：通知權限由瀏覽器管理。你按「通知」開啟、而且瀏覽器支援網頁推播時，伺服器會存：瀏覽器推播服務（Google、Apple、Mozilla、Microsoft）給的推播網址與加密金鑰，以及你的約略位置（小數點後 3 位，約 100 公尺），只用來在附近 1 公里內有發放或活動開始時送通知給你；你移動超過約 300 公尺、網頁開著時會更新成新的約略位置，不保留舊的位置。通知內容加密後經由推播服務送到你的手機。你再按一次「通知」關掉、推播服務回報訂閱已失效、或 30 天沒打開網頁，就會刪除。
  • 回報貼文：你按「＋回報」送出 Threads 貼文連結時，伺服器會記錄這次回報、你回報的貼文，以及你 IP 位址的加鹽雜湊值（無法還原成 IP），只用來限制回報頻率、避免同一人重複回報。這些紀錄 30 天後自動刪除。（以前詳細資料裡的「回報已發完」按鈕已經拿掉，不再收這類回報。）回報貼文時，也會記下你瀏覽器裝置代碼（見下方「漂流瓶」）的加鹽雜湊值，只用來讓你在同一個瀏覽器列出、刪除自己的回報，以及限制同一個瀏覽器的回報頻率，跟回報紀錄一起在 30 天後刪除。
  • 沒有連結的回報（已停止收件）：以前可以貼文字、上傳截圖或自己填活動。送出的文字、自己填的資料跟貼文連結的回報一樣存在伺服器上，放上雷達的大家看得到；截圖只交給 Cloudflare Workers AI 讀出裡面的字，圖片本身沒有存。這些資料跟一般回報一樣在 30 天內刪除，現在不再收這類回報。
  • 回報問題：你在詳細資料按「回報問題」時，伺服器會存：問題類型、你寫的說明、那一則當時的標題與地點、回報時間，以及裝置代碼與 IP 的加鹽雜湊值（只用來限制回報次數、避免同一個人重複回報）。這些只有管理者看得到，不會公開，30 天後刪除。
  • 固定據點回報（已停止收件）：以前送出的 Threads 連結、你填的地點、開放時間與補充說明，存在伺服器上用來審核與顯示；另外存一組隨機的查詢代碼與取消碼，讓你在同一個瀏覽器查進度或取消。IP 的加鹽雜湊值 30 天後清除。現在固定據點一樣用「回報 Threads 貼文」貼連結，不再收這類資料。
  • 漂流瓶：不需要登入。第一次使用時，你的瀏覽器會產生一組隨機的裝置代碼（存在 localStorage），伺服器只存它的加鹽雜湊值，用來辨認哪些瓶子是你丟的、收藏的，以及限制每天丟幾個。你丟的瓶子會存：內容、丟出時間、瓶子的位置（丟出去就落在你 1 km 內的隨機位置，不是你站的地方），以及你丟的地方：只用來讓瓶子在丟的地方 1 km 內漂，不會給任何人看（也不會給收藏的人），24 小時後就刪掉；24 小時後瓶子的位置換成汪星（網站裡虛構的星球）海上的位置，位置跟著更新。走到瓶子 1 km 內的人都看得到內容和照片（收藏了也一樣）；位置是瀏覽器送出的，有心人可以假造，所以內容和照片請當成公開的，不要寫、拍不想讓陌生人看到的東西。別人看到的丟出時間只到整點。打開瓶子、收藏、看照片、檢舉時你的座標（地球上的 GPS 位置，或你在汪星上的位置）只用來確認距離，不會儲存；伺服器只記你這一個小時打開、看照片幾次（裝置代碼與 IP 的加鹽雜湊值，不記看了哪個瓶子），用來擋用程式大量讀取，2 小時內刪除。瓶子丟出 31 天後沉下去，連同收藏與檢舉紀錄在之後 30 天內刪除；丟的人隨時可以收回瓶子（不用走過去；找不到瓶子可以照資料刪除說明申請），收回時內容、位置、照片、收藏與檢舉紀錄馬上刪除，只留編號、丟出時間和裝置代碼雜湊用來算每天的額度，30 天內一起刪除；IP 的加鹽雜湊值只用來限制頻率，也一起刪除。例外：收藏的瓶子會放進收藏的人的「漂流瓶收藏」，信的內容會保留到收藏的人移出收藏為止，但瓶子沉下去 30 天後會刪掉丟的人的裝置代碼雜湊與 IP 雜湊，之後無法連回丟的人。瓶子內容會交給 Cloudflare Workers AI 自動審核；沒通過審核的，伺服器會記下內容、沒通過的原因、時間，以及裝置代碼和 IP 的加鹽雜湊值 7 天（不記位置，照片只記有沒有附、不存照片），只有管理者看得到，用來改善審核、擋下一直送沒通過的瓶子，7 天後自動刪除。照片：可以附一張。照片先在你的瀏覽器縮小、重新存檔（拍照的位置、相機型號、拍攝時間等 EXIF 資訊會拿掉），伺服器收到後再檢查一次、拿掉剩下的中繼資料，交給 Cloudflare Workers AI 看圖審核，通過才存進 Cloudflare R2；丟的人、收藏的人和走到瓶子附近的人拿得到，跟瓶子一起刪除（收藏的漂流瓶留著的話，照片也留到移出收藏、瓶子刪除為止）。請不要拍到別人的臉、證件、車牌或門牌。「瓶子證明」的簽章是伺服器用瓶子的編號、丟出時間和內容的 SHA-256 雜湊值當場算出來的，不另外儲存。
  • 收集卡（尋找小法）：不需要登入。你在汪星點到小法拿到卡片時，伺服器會存：哪一張卡、拿到的時間、在公園哪一區找到（是小法當時在虛擬公園裡的位置，不是你的位置），以及裝置代碼的加鹽雜湊值（用來認出你拿過哪些卡、算出你是第幾位找到的）。卡片紀錄會保留，讓你隨時在卡冊看得到；IP 的加鹽雜湊值只用來限制頻率，30 天內刪除。清除瀏覽器資料後裝置代碼會換新，之前的卡就連不回來；換裝置前可以在選單「說明」按「換裝置」產生引繼碼，在新裝置輸入就能把卡片、道具、許願和漂流瓶收藏（收藏的漂流瓶）搬過去（自己丟的瓶子不搬）。引繼碼只存加鹽雜湊值，24 小時後失效、用過一次就失效，過期的在 30 天內刪除；產生、輸入引繼碼時 IP 的加鹽雜湊值只用來限制次數，30 天內刪除。
  • 許願（用順幣）：不需要登入。你在「願望」投順幣許願或送出調整時，伺服器會存：你寫的想法、你填的暱稱與參考連結（選填）、送出時間、審核進度與管理者的回覆，以及裝置代碼與 IP 的加鹽雜湊值（裝置代碼用來讓你在「我的願望」看進度、退回順幣；IP 只用來限制送出次數，30 天內刪除）。內容只有管理者看得到，不會公開；通過後做出來的東西會放上網站，有填暱稱才會在說明頁的「實現的願望」寫「點子來自」你的暱稱。不通過、做不出來或你自己撤回的願望，30 天後刪除。
  • 服務紀錄：本服務架設在 Cloudflare 與 GitHub Pages，這些平台可能依其政策保留一般連線紀錄（例如 IP 位址、瀏覽器類型），本服務不另外收集或使用這些資料；伺服器已關閉 Cloudflare Workers 的逐筆請求紀錄（請求網址裡可能有你的座標），只留程式自己寫的錯誤與排程紀錄。

二、來自 Threads 的資料

本服務透過 Meta 提供的 Threads API，以固定關鍵字搜尋公開貼文，處理方式如下：

  • 取得的內容：貼文編號、內文、發文時間、作者的公開使用者名稱、貼文連結。不取得私人訊息、追蹤名單或任何非公開內容。
  • 用途：以自動化方式（包含 AI 文字判讀）找出貼文中的發放或活動時間與地點，並把地點轉成地圖座標，顯示在雷達與地圖上，同時附上原貼文連結。不用於廣告、不建立個人檔案、不出售或分享給第三方。
  • 公開統計：「雷達統計」頁會列出最近 30 天放上雷達的活動來自哪些公開的 Threads 帳號，只寫帳號名稱、幾則貼文、幾場活動，不寫內容。只算確認放上雷達的貼文，作者刪掉的貼文不算；一個帳號至少 2 則才列，最多列 20 個。除此之外，其他統計都只有加總的數字。不想出現在統計裡，請依資料刪除說明聯絡我們，我們會把帳號排除。
  • 保存期限：貼文與解析結果最多保存 30 天，之後自動刪除。
  • 使用者回報的貼文：使用者貼上 Threads 公開貼文連結時，本服務會讀取 Meta 提供給網站嵌入用的該則貼文公開頁面（只讀取那一則），取得內文與作者的公開使用者名稱，用上述相同方式判讀與保存。之後每 30 分鐘重讀一次，確認貼文是否刪除或修改；貼文刪除後相關的發放與活動會下架。
  • 使用者回報的活動頁：使用者貼上 ACCUPASS 活動通、OPENTIX 兩廳院文化生活的活動頁連結時，本服務會讀取那一頁公開的活動資料（名稱、時間、地點、主辦單位、活動介紹），用來判讀與保存，原文連結指回活動頁。之後每 30 分鐘重讀一次，活動頁刪除或標成取消就下架。
  • 授權帳號：本服務的營運者以自己的 Threads 帳號授權搜尋，只保存該帳號的存取權杖，用來呼叫 API。

三、第三方服務

  • Meta Threads API：搜尋公開貼文。
  • Threads 公開貼文的嵌入頁面：讀取使用者回報的單一則貼文。
  • 新聞網站的公開 RSS（Yahoo 新聞，含其轉載的各家報導）：讀取含關鍵字的報導，判讀後只保留標題、短摘要與原文連結。
  • 台北大洋流官網公開的「未來航線」資料：車掃日期、地點與加油點。
  • Cloudflare（Workers、D1、Workers AI、R2、Pages）：網站與伺服器、資料庫、文字判讀與漂流瓶照片審核、漂流瓶照片儲存。
  • OpenStreetMap Nominatim：把地點文字轉成座標，只送出地點文字。
  • OpenStreetMap 圖磚：地圖畫面，由你的瀏覽器直接向 OpenStreetMap 下載。
  • GitHub Pages：網站備用位址。

四、你的權利

  • 如果你是 Threads 貼文的作者，希望本服務移除與你貼文相關的資料，請依資料刪除說明聯絡我們，我們會在 7 天內刪除。
  • 你可以隨時在瀏覽器關閉定位或通知權限，或清除本網站的網站資料。

五、兒童隱私

本服務不針對 13 歲以下兒童設計，也不刻意收集兒童的資料。

Privacy Policy (English summary)

What this service does. 洋流雷達 (Current Radar) is a web tool that finds public Threads posts announcing in-person giveaways and events, extracts the time and place, and shows them on a radar and map relative to the visitor's location.

Website visitors. No sign-up or login is required. If you allow location access, your approximate coordinates are sent to our server only to look up nearby events; they are not stored or logged. Preferences (theme, range, manual location) stay in your browser's localStorage. When you submit a Threads post link or report that a giveaway has ended, we store the report together with a salted hash of your IP address (not reversible) only for rate limiting; these records are deleted after 30 days. Post-link submissions also store a salted hash of your browser's random device code, used only so you can list and delete your own submissions from the same browser and to rate-limit submissions per browser; it is deleted with the submission record after 30 days. Submissions without a link (pasted text, a screenshot, or a filled-in form) are no longer accepted; ones sent earlier were stored the same way (a screenshot was only read by Cloudflare Workers AI, the image itself was not stored) and are deleted within 30 days.

Drift bottles. Without logging in, your browser creates a random device code (kept in localStorage); the server stores only its salted hash to know which bottles you dropped or picked and to rate-limit. A dropped bottle stores its text, time, its own location (a random spot within 1 km of where you stood, not your position), and where you dropped it — used only to keep the bottle drifting within 1 km of that spot, never shown to anyone (including the person who collects it), and deleted after 24 hours. After 24 hours the bottle's location is replaced with a spot on the sea of 汪星 (a fictional planet on this site). Anyone within 1 km of a bottle can read its text and see its photo, even after someone has collected it; because the location is sent by the browser and can be faked, treat the text and photo as public. Others only see the drop time rounded to the hour. Your coordinates when opening, collecting, viewing a photo or reporting (your GPS position on Earth, or your position on 汪星) are only used to check the distance and are not stored; the server only counts how many bottles you opened or photos you viewed in the current hour (salted hashes of the device code and IP, not which bottles) to stop bulk reading, deleted within 2 hours. The dropper can withdraw a bottle at any time without walking to it, which deletes its text, location, photo, picks and reports immediately. Bottles sink 31 days after being dropped and are deleted, with pick and report records, within the following 30 days. A picked bottle goes into the picker's letter collection and its text is kept until they remove it, but the dropper's device hash and IP hash are deleted 30 days after the bottle sinks. Bottle text is screened automatically with Cloudflare Workers AI; for bottles that fail screening, the server keeps the text, the reason, the time and salted hashes of the device code and IP for 7 days (no location; only whether a photo was attached), visible only to the administrator, to improve screening and to stop repeated failed attempts. You may attach one photo: your browser shrinks and re-saves it (removing EXIF data such as location, camera and time), the server strips any remaining metadata, Cloudflare Workers AI screens the image, and it is stored in Cloudflare R2, available to the dropper, the collector and people near the bottle, and deleted with the bottle. The "bottle proof" signature is computed on request from the bottle number, drop time and the SHA-256 hash of the text, and is not stored.

Threads data. Using the Meta Threads API we search public posts for a fixed keyword. We process the post ID, text, timestamp, author's public username and permalink, solely to extract the time and location of giveaways and events and display them with a link to the original post. Our public statistics page (“雷達統計”) also lists which public Threads accounts the events shown on the radar came from in the last 30 days — only the username and how many posts and events, never the text; only posts that were confirmed onto the radar and not deleted by the author count, and an account is listed only with at least 2 posts (top 20). Authors can ask to be excluded via the data deletion instructions. Apart from this, we do not use the data for advertising, profiling, or sale, and we do not share it with third parties. Posts and extracted data are automatically deleted after 30 days. For post links submitted by users, we read that single post's public embed page to obtain its text and author's public username, process it the same way, and re-read it every 30 minutes to detect deletion or edits. The only access token stored is the operator's own Threads token used to call the API.

Event pages. When a user submits an ACCUPASS (accupass.com) or OPENTIX (opentix.life) event page link, we read that page's public event data (name, time, place, organizer, description) to put the event on the radar with a link back to the page, and re-read it every 30 minutes to take it down if the page is removed or the event is cancelled.

Processors. Meta Threads API, public news RSS feeds (Yahoo News; only title, short excerpt and link are kept), the public route data of the official 台北大洋流 site, public ACCUPASS and OPENTIX event pages submitted by users, Cloudflare (Workers, D1, Workers AI, R2, Pages), OpenStreetMap Nominatim and tiles, GitHub Pages.

Deletion and contact. See the data deletion instructions. Questions: GitHub Issues.
