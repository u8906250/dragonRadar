隱私權政策

最後更新：2026 年 10 月 17 日（加入「回報貼文」）

洋流雷達（以下稱「本服務」）是一個網頁工具，從 Threads 的公開貼文中找出「某時某地的免費發放或可參加的活動」，在雷達畫面上顯示相對位置。本政策說明本服務處理哪些資料，以及如何處理。

一、網站使用者

  • 不需要註冊或登入。本服務不要求你提供姓名、Email、電話或任何帳號。
  • 位置：你允許定位後，瀏覽器會把你的大略座標送到本服務的伺服器，只用來查詢附近的發放資訊。伺服器不儲存你的座標，也不記錄你的位置軌跡。距離與方位是在你的手機上計算。
  • 手機上的設定：你選擇的主題、雷達範圍、手動設定的位置，只存在你自己瀏覽器的 localStorage，不會傳到伺服器。
  • 通知：通知權限由瀏覽器管理，本服務不收集推播識別碼。
  • 回報貼文與「回報已發完」：你按「＋回報」送出 Threads 貼文連結，或在活動詳細資料按「回報已發完」時，伺服器會記錄這次回報、你回報的貼文或活動，以及你 IP 位址的加鹽雜湊值（無法還原成 IP），只用來限制回報頻率、避免同一人重複回報。這些紀錄 30 天後自動刪除。你回報過哪些活動，也會存在你瀏覽器的 localStorage，避免重複回報。回報貼文時，也會記下你瀏覽器裝置代碼（見下方「漂流瓶」）的加鹽雜湊值，只用來讓你在同一個瀏覽器列出、刪除自己的回報，以及限制同一個瀏覽器的回報頻率，跟回報紀錄一起在 30 天後刪除。
  • 固定據點回報（已停止收件）：以前送出的 Threads 連結、你填的地點、開放時間與補充說明，存在伺服器上用來審核與顯示；另外存一組隨機的查詢代碼與取消碼，讓你在同一個瀏覽器查進度或取消。IP 的加鹽雜湊值 30 天後清除。現在固定據點一樣用「回報 Threads 貼文」貼連結，不再收這類資料。
  • 漂流瓶：不需要登入。第一次使用時，你的瀏覽器會產生一組隨機的裝置代碼（存在 localStorage），伺服器只存它的加鹽雜湊值，用來辨認哪些瓶子是你丟的、撿過的，以及限制每天丟幾個。你丟的瓶子會存：內容、丟出時間，以及隨機漂開約 100 m 後的位置（不存你真正的位置）；之後瓶子會自動往附近熱鬧的地方漂，位置跟著更新。撿瓶子時你的座標只用來確認距離，不會儲存。瓶子 7 天後漂走，連同撿起與檢舉紀錄在 30 天內刪除；IP 的加鹽雜湊值只用來限制頻率，也一起刪除。例外：撿到的人把信收藏起來時，信的內容會保留到收藏的人移出收藏為止，但 30 天後會刪掉丟的人的裝置代碼雜湊與 IP 雜湊，之後無法連回丟的人。瓶子內容會交給 Cloudflare Workers AI 自動審核。
  • 服務紀錄：本服務架設在 Cloudflare 與 GitHub Pages，這些平台可能依其政策保留一般連線紀錄（例如 IP 位址、瀏覽器類型），本服務不另外收集或使用這些資料。

二、來自 Threads 的資料

本服務透過 Meta 提供的 Threads API，以固定關鍵字搜尋公開貼文，處理方式如下：

  • 取得的內容：貼文編號、內文、發文時間、作者的公開使用者名稱、貼文連結。不取得私人訊息、追蹤名單或任何非公開內容。
  • 用途：以自動化方式（包含 AI 文字判讀）找出貼文中的發放或活動時間與地點，並把地點轉成地圖座標，顯示在雷達與地圖上，同時附上原貼文連結。不用於廣告、不建立個人檔案、不出售或分享給第三方。
  • 保存期限：貼文與解析結果最多保存 30 天，之後自動刪除。
  • 使用者回報的貼文：使用者貼上 Threads 公開貼文連結時，本服務會讀取 Meta 提供給網站嵌入用的該則貼文公開頁面（只讀取那一則），取得內文與作者的公開使用者名稱，用上述相同方式判讀與保存。之後每 30 分鐘重讀一次，確認貼文是否刪除或修改；貼文刪除後相關的發放與活動會下架。
  • 授權帳號：本服務的營運者以自己的 Threads 帳號授權搜尋，只保存該帳號的存取權杖，用來呼叫 API。

三、第三方服務

  • Meta Threads API：搜尋公開貼文。
  • Threads 公開貼文的嵌入頁面：讀取使用者回報的單一則貼文。
  • 新聞網站的公開 RSS（Yahoo 新聞，含其轉載的各家報導）：讀取含關鍵字的報導，判讀後只保留標題、短摘要與原文連結。
  • 台北大洋流官網公開的「未來航線」資料：車掃日期、地點與加油點。
  • Cloudflare（Workers、D1、Workers AI、Pages）：網站與伺服器、資料庫、文字判讀。
  • OpenStreetMap Nominatim：把地點文字轉成座標，只送出地點文字。
  • OpenStreetMap 圖磚：地圖畫面，由你的瀏覽器直接向 OpenStreetMap 下載。
  • GitHub Pages：網站備用位址。

四、你的權利

  • 如果你是 Threads 貼文的作者，希望本服務移除與你貼文相關的資料，請依資料刪除說明聯絡我們，我們會在 7 天內刪除。
  • 你可以隨時在瀏覽器關閉定位或通知權限，或清除本網站的網站資料。

五、兒童隱私

本服務不針對 13 歲以下兒童設計，也不刻意收集兒童的資料。

六、政策變更與聯絡方式

政策若有變更會更新本頁的日期。有任何問題請到 GitHub Issues 留言。

Privacy Policy (English summary)

What this service does. 洋流雷達 (Current Radar) is a web tool that finds public Threads posts announcing in-person giveaways and events, extracts the time and place, and shows them on a radar and map relative to the visitor's location.

Website visitors. No sign-up or login is required. If you allow location access, your approximate coordinates are sent to our server only to look up nearby events; they are not stored or logged. Preferences (theme, range, manual location) stay in your browser's localStorage. When you submit a Threads post link or report that a giveaway has ended, we store the report together with a salted hash of your IP address (not reversible) only for rate limiting; these records are deleted after 30 days. Post-link submissions also store a salted hash of your browser's random device code, used only so you can list and delete your own submissions from the same browser and to rate-limit submissions per browser; it is deleted with the submission record after 30 days.

Drift bottles. Without logging in, your browser creates a random device code (kept in localStorage); the server stores only its salted hash to know which bottles you dropped or picked and to rate-limit. A dropped bottle stores its text, time, and a location randomly moved about 100 m away from where you stood (your real position is not stored). Your coordinates when picking a bottle are only used to check the distance and are not stored. Bottles expire after 7 days and are deleted, with pick and report records, within 30 days. Bottle text is screened automatically with Cloudflare Workers AI.

Threads data. Using the Meta Threads API we search public posts for a fixed keyword. We process the post ID, text, timestamp, author's public username and permalink, solely to extract the time and location of giveaways and events and display them with a link to the original post. We do not use the data for advertising, profiling, or sale, and we do not share it with third parties. Posts and extracted data are automatically deleted after 30 days. For post links submitted by users, we read that single post's public embed page to obtain its text and author's public username, process it the same way, and re-read it every 30 minutes to detect deletion or edits. The only access token stored is the operator's own Threads token used to call the API.

Processors. Meta Threads API, public news RSS feeds (Yahoo News; only title, short excerpt and link are kept), the public route data of the official 台北大洋流 site, Cloudflare (Workers, D1, Workers AI, Pages), OpenStreetMap Nominatim and tiles, GitHub Pages.

Deletion and contact. See the data deletion instructions. Questions: GitHub Issues.
